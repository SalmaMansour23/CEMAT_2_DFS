Start button's Q output automatically starts the motor. Stop button's Q output automatically stops the
motor. These are the only signals needed from each button.

Sensor_DI's Q output is a safety interlock into the motor:
when the digital value's output signal is on, invert it so the motor's
protection interlock input goes to 0 and the motor trips/stops. Connect it
to the operating interlock input of the motor.

The three inputs (start button, stop button, Sensor_DI) are independent -
none of them connect to each other, only to the motor.

Do not connect anything else, only the absolutely necessary connections.
